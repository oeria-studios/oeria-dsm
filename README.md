<h1 align="center">OERIA - Development Server Manager</h1>

<p align="center">
  <em>Avec cet outil, vous pourrez créer et gérer des serveurs en local sur votre PC.</em>
</p>

### 🍃 Lancer le dashboard
- Étape 1 -> Exécuter windows powershell en administrateur
- Étape 2 -> taper `cd <chemin d'accès vers le dossier oeria-dsm>`
- Étape 3 -> dans le terminal taper `npm start`

### 🔥 Jeux compatible
- Minecraft
- Garry's mod
- Counter-Strike 2
- Valheim
- Vintage Story
- Rust
- Project Zomboid
- Palworld
- FiveM
- 7 Days to Die

### 🍬 Fonctionnalités
- Gestion multi-serveurs
- Console en direct
- Monitoring / stats (toutes les 2s)
- Éditeur de fichiers de configuration
- Paramètres par serveur
- Thème sombre / clair

> [!note]
> Ce projet a été créé avec l'aide de l'IA pour certaines fonctionnalités.
