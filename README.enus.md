<h1 align="center">OERIA - Development Server Manager</h1>

<p align="center">
  <em>With this tool, you can create and manage servers locally on your PC.</em>
</p>

🌐 **Languages / Langues :**
[English](README.enus.md) | [Français](README.md)

### 🍃 Launching the Dashboard
- Step 1 -> Run Windows PowerShell as administrator
- Step 2 -> Type `cd <path to the oeria-dsm folder>`
- Step 3 -> In the terminal, type `npm start`

### 🔥 Compatible Games
- Minecraft
- Garry's Mod
- Counter-Strike 2
- Valheim
- Vintage Story
- Rust
- Project Zomboid
- Palworld
- FiveM
- 7 Days to Die

### 🍬 Features
- Multi-server management
- Live console
- Monitoring / stats (every 2s)
- Configuration file editor
- Per-server settings
- Dark / light theme

> [!NOTE]
> This project was created with the help of AI for certain features.
